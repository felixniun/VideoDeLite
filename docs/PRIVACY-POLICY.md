# VideoDelite 隐私政策

**最后更新：2026-10-03**

VideoDelite 的设计原则是**本地优先**：您的视频属于您，永远留在您的电脑上。

## 我们不收集的数据（承诺不上传）

- 视频文件或其任何内容
- 视频文件名、路径、大小
- 视频 Metadata（拍摄设备、GPS、时间等）
- FFmpeg / FFprobe 命令与输出
- 压缩参数、压缩结果、压缩行为统计
- 崩溃日志（除非您主动点击"导出日志"并自行发送）

## 本地存储的数据

以下数据仅保存在您的电脑 `%LOCALAPPDATA%\VideoDelite`：

| 数据 | 用途 | 清除方式 |
|---|---|---|
| 任务历史（SQLite） | 显示压缩记录 | 设置 → 数据 → 清除历史 |
| 应用设置 | 记住您的偏好 | 卸载时勾选删除 |
| 日志 | 排查问题，7 天自动清理，500MB 上限 | 设置 → 日志 → 打开/导出 |

## 联网行为（仅在您使用账号功能时）

VideoDelite 的视频压缩**完全离线工作**。只有当您主动使用账号功能时，才会连接授权服务器，且仅传输：

- 注册/登录：邮箱、用户名、密码（Argon2id 哈希后传输，明文永不离开您的电脑）
- 邮箱验证：验证码校验（验证码邮件由 Resend 邮件服务发送）
- 设备激活：随机生成的 Installation ID（非硬件指纹）、应用版本号

**Professional 授权激活后，日常压缩完全离线可用**，不因网络断开而中断。

## 账号数据

- 您可以随时在设置中删除账号；服务端仅保留必要的匿名安全记录
- 删除账号不影响本机的视频、历史、设置
- 密码使用 Argon2id 哈希存储，Token 存储在 Windows 凭据管理器中

## 第三方组件

- FFmpeg / FFprobe（gyan.dev 构建）：仅作为本地子进程运行，声明见安装目录 `THIRD-PARTY-NOTICES.txt`
- Resend：仅在发送验证码邮件时作为邮件通道，不接收任何视频相关信息
