## 全景目录树

```
VideoDelite/
│
├── 🖥️ 桌面客户端入口（根目录 Go 文件）
│   ├── main.go                  # 程序入口：①检测 WebView2 ②启用原生拖拽 ③启动 Wails 窗口
│   ├── app.go                   # 绑定层：前端能调用的所有 Go 方法都在这（分析/建任务/历史/设置/账号/日志）
│   ├── cli.go                   # --cli 无头模式：不打开窗口也能"分析/压缩"，用于自动化测试
│   ├── platform_windows.go      # 【仅Win】读 Windows 系统语言和深浅色主题
│   ├── platform_other.go        # 【非Win】上一行的空实现（保证 Linux/Mac 也能编译）
│   ├── webview2_windows.go      # 【仅Win】启动前查注册表：没装 WebView2 就弹窗引导，绝不静默安装
│   ├── webview2_other.go        # 【非Win】空实现
│   ├── webviewdata.go           # 把界面缓存改放到 Data\WebView2（默认会散落到 Roaming）
│   ├── go.mod / go.sum          # Go 依赖清单与版本锁
│   └── wails.json               # Wails 配置：程序名、前端构建命令、exe 版本信息
│
├── 📦 internal/ —— 客户端核心逻辑（14 个包；Go 规定 internal 外部项目引用不到）
│   │
│   ├── media/                   # 【媒体分析】
│   │   ├── mediainfo.go         #   数据模型 + ffprobe JSON 解析（含 rotation 数字/字符串双格式兼容）
│   │   ├── mediainfo_test.go    #   回归测试：DJI 无人机 rotation 数字格式不再崩溃
│   │   └── analyzer.go          #   调 ffprobe 分析文件；文件夹递归扫描找视频
│   │
│   ├── encoder/                 # 【编码策略】（红线：前端永远不直接拼 FFmpeg 命令）
│   │   ├── bitrate.go           #   冻结码率表：H.264 分档、H.265×0.75、超4K像素比、低清下限
│   │   ├── hardware.go          #   探测 NVENC/QSV/AMF/CPU 谁能用（真跑测试编码），自动选择
│   │   └── builder.go           #   把用户配置翻译成 FFmpeg 参数（各编码器参数名不同在这里消化）
│   │
│   ├── task/                    # 【任务系统】
│   │   ├── task.go              #   任务数据模型 + 8 种状态（等待→编码→验证→完成…）
│   │   ├── manager.go           #   队列调度（同时压 1-3 个）、暂停/取消/重试、失败回退CPU、写历史
│   │   ├── helpers.go           #   小工具函数
│   │   └── disk_windows.go / disk_other.go   # 查目标盘剩余空间，不够就预警
│   │
│   ├── ffmpegx/                 # 【FFmpeg 进程管理】
│   │   ├── runner.go            #   启动 ffmpeg 子进程，实时解析进度（百分比/速度/码率）
│   │   ├── suspend_windows.go / suspend_other.go   # 暂停=挂起进程线程，恢复=唤醒
│   │   └── job_windows.go / job_other.go           # 崩溃保护：主程序死了系统自动杀 ffmpeg
│   │
│   ├── validation/              # 【输出验证】
│   │   └── validation.go        #   压完必须用 ffprobe 复检：容器/编码/分辨率/时长不对=失败
│   │
│   ├── history/                 # 【历史记录】
│   │   └── history.go           #   存 SQLite：输入输出文件、压缩率、耗时、成功失败
│   │
│   ├── settings/                # 【应用设置】
│   │   └── settings.go          #   语言/主题/输出目录/编码器偏好/API服务器地址/并行数
│   │
│   ├── logging/                 # 【日志】
│   │   └── logging.go           #   自动清理：7天过期、总量500MB、单任务20MB
│   │
```

## 核心数据流（理解文件之间怎么协作）

```
【压缩一条视频的完整旅程】

  拖文件进来 (HomeView)
      │ Wails 原生拖拽 → 拿到真实文件路径
      ▼
  app.go: AnalyzeFiles()
      │
      ▼
  internal/media/analyzer.go ──调用──▶ ffprobe.exe（读视频信息）
      │
      ▼ 返回 MediaInfo（分辨率/编码/HDR…）
  HomeView 显示 + 用户点"开始压缩"
      │
      ▼
  internal/task/manager.go 排队
      │
      ├─▶ internal/encoder/hardware.go  选编码器（NVENC优先，不行用CPU）
      ├─▶ internal/encoder/builder.go   生成 FFmpeg 参数
      │
      ▼
  internal/ffmpegx/runner.go 启动 ffmpeg.exe
      │  ↑ 每 0.3 秒推送进度到界面（TasksView 进度条动起来）
      │  ↓ ffmpeg 干完退出
      ▼
  internal/validation/validation.go 用 ffprobe 复检输出
      │
      ├─ 不合格 ──▶ 任务标记失败（绝不给用户坏文件）
      ▼ 合格
  internal/history/history.go 写入历史 + 文件移到输出目录
```

```
【账号登录的旅程】（与上面完全独立，视频数据永不上传）

  SettingsView 输入邮箱密码
      ▼
  app.go: AccountLogin()
      ▼
  internal/account/account.go ──HTTPS──▶ 服务器（Debian Docker）
                                             │
                              server/handlers.go (Gin 路由)
                                             │
                              server/auth.go 验证密码哈希
                                             │
                              server/store_impl.go 查 SQL Server
                                             │
                              返回 JWT 令牌 → 存 Windows 凭据管理器
                                             │
  internal/auth/auth.go 状态机切到"已授权"
                                             │
  ▶ 解锁专业模式（只影响能否"开始新任务"，运行中的压缩永不受影响）
```

## "我想改 XX" 速查表

| 想改什么 | 改哪个文件 |
|---|---|
| 压缩画质档位、码率数值 | `internal/encoder/bitrate.go` |
| 支持新编码器（如 AV1） | `internal/encoder/hardware.go` + `builder.go` |
| 界面文字/加语言 | `frontend/src/i18n/index.ts` |
| 界面配色、圆角、字体 | `frontend/src/style.css` 开头的变量区 |
| 首页拖放区/参数面板布局 | `frontend/src/views/HomeView.vue` |
| 授权规则（谁能用专业模式） | `internal/auth/auth.go` |
| 服务端接口（加新接口） | `server/handlers.go` |
| 管理后台页面 | `server/adminui.html`（单文件自包含） |
| 数据库加字段/表 | 客户端 `internal/db/db.go`；服务端 `server/store.go` |
| 安装程序行为 | `installer/installer.nsi` |
| 默认 API 服务器地址 | `internal/settings/settings.go` |
| 日志保留策略 | `internal/logging/logging.go` |

## 【本地 gitignore】文件一览（在您电脑上有、GitHub 上没有）

| 文件 | 为什么不入库 |
|---|---|
| `cmd/videoserver/config.json` | 含数据库密码、邮件 API Key |
| `server/jwt.secret` | 令牌签名密钥 |
| `build/keys/*.pfx` | 代码签名证书 |
| `build/bin/`、`build/dist/` | 编译产物（随时可重新生成） |
| `build/cache/` | ffmpeg 下载缓存、部署用真实配置 |
| `debian/` | 服务器部署副本（含真实密码） |
| `frontend/node_modules/` | npm 依赖（`npm install` 自动还原） |
| `android/dist`、`android/keystore*` | 安卓 APK 与签名密钥（若安卓端恢复） |
